04 Lab · acme.local

Isolated Active Directory domain: zero to Domain Admin

Self-built lab. Real misconfigurations, no CTF shortcuts.

Attack path in six steps

  1. 1

    Starting point

    Kali, outside the domain

    No domain account.

    Result no access

  2. 2

    Reconnaissance

    Unauthenticated enumeration

    Information the network exposes to an unauthenticated host.

    Result initial map of the network

  3. 3

    Valid users

    Kerberos user enumeration

    Different Kerberos responses for existing and nonexistent names.

    Result list of valid usernames

  4. 4

    First account

    AS-REP roasting

    Account with Kerberos pre-authentication disabled; password cracked offline.

    Result credentials for one account

  5. 5

    Privilege escalation

    ACL abuse · GenericAll

    An over-granted GenericAll right (full control over another object) in an ACL.

    Result elevated privileges in the domain

  6. 6

    Domain compromise

    Domain Admin on DC01

    Full control of every account and machine.

    Result the entire domain

06 Defense

Defending self-managed production systems

Systems left unnamed; controls currently in place.

  • Full pentest

    Static and live. Critical and medium findings fixed.

  • Server-side authorization

    Plan limits enforced on the server, out of the client’s reach.

  • Key-only SSH

    No password login. Automatic rollback of changes.

  • Watchdog

    Process monitoring with alerts and automatic restart.

  • Multi-agent review

    Adversarial verification; each finding must survive a refutation attempt.

  • security.txt

    Published. Reporting channel for other researchers.
